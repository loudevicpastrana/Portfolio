# Final Project

## Objective

Specify, design, implement and debug a multi-task (multi-threaded) embedded project using a real-time operating system.

#### Functional Specification: MP3 player with TouchScreen and IoT broadcasting

1. MP3 Player functionality:
   * Start playing (from the beginning of the song)
   * Stop
   * Indicate on the LCD what song it is playing
   * Play NEXT song
   * Play PREVIOUS song

2. GUI Touchscreen functionality:
   * PLAY button
   * STOP button
   * PREVIOUS button
   * NEXT button
   * Indicate what song title is playing on screen
   
3. IoT Functionality  

   * broadcast what song is playing now
   * PLAY Command
   * STOP command
   * PREVIOUS command
   * NEXT command
